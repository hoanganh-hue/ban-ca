# Admin Dashboard - Underwater Fishing Game\n\nA comprehensive admin dashboard for managing the underwater fishing game, built with React, TypeScript, and Tailwind CSS.\n\n## Features\n\n### 📊 Dashboard Overview\n- Real-time system metrics and statistics\n- Active user monitoring\n- Game session analytics\n- Revenue and performance tracking\n- Quick action shortcuts\n\n### 👥 User Management\n- View and search all registered users\n- User profile management (currency, score, level)\n- User status control (active, inactive, banned)\n- Bulk operations and user export\n- Detailed user activity logs\n\n### 🎮 Game Session Monitoring\n- Real-time active session tracking\n- Session history and analytics\n- Fish catching statistics\n- Currency earning metrics\n- Session duration analysis\n\n### 📝 Content Management\n- Game item management (weapons, consumables, materials)\n- Fish species configuration\n- Achievement system management\n- Game settings and parameters\n- Content categorization by rarity\n\n### ⚙️ System Administration\n- System health monitoring\n- Performance metrics (CPU, Memory, Disk)\n- Service status tracking (API, Database, Redis, WebSocket)\n- Maintenance mode control\n- Configuration management\n\n### 👤 Admin Profile\n- Personal profile management\n- Password change functionality\n- Notification preferences\n- Activity audit log\n- Theme and language settings\n\n## Technology Stack\n\n- **Frontend**: React 18 + TypeScript\n- **Build Tool**: Vite\n- **Styling**: Tailwind CSS\n- **Icons**: Lucide React\n- **Routing**: React Router DOM v6\n- **State Management**: React Query (TanStack Query)\n- **HTTP Client**: Axios\n- **Forms**: React Hook Form + Zod validation\n- **UI Components**: Headless UI\n- **Notifications**: React Hot Toast\n- **Charts**: Recharts\n\n## Project Structure\n\n```\nadmin-dashboard/\n├── public/\n│   └── index.html\n├── src/\n│   ├── components/\n│   │   ├── layout/\n│   │   │   └── API\n\n### Local Development\n\n1. **Clone the repository**\n   ```bash\n   git clone <repository-url>\n   cd admin-dashboard\n   ```\n\n2. **Install dependencies**\n   ```bash\n   npm install\n   ```\n\n3. **Configure environment**\n   ```bash\n   cp .env.example .env.local\n   ```\n   \n   Update `.env.local` with your backend API URL:\n   ```bash\n   VITE_API_URL=http://localhost:8080/admin/api\n   ```\n\n4. **Start development server**\n   ```bash\n   npm run dev\n   ```\n\n5. **Access the dashboard**\n   - URL: http://localhost:3001\n   - Default login: admin / (check server configuration)\n\n### Production Build\n\n1. **Build the application**\n   ```bash\n   npm run build\n   ```\n\n2. **Preview the build**\n   ```bash\n   npm run preview\n   ```\n\n## Docker Deployment\n\nThe admin dashboard is containerized and can be deployed with Docker.\n\n### Standalone Deployment\n\n```bash\n# Build the image\ndocker build -t underwater-game-admin .\n\n# Run the container\ndocker run -p 3001:80 \\\n  -e VITE_API_URL=https://your-domain.com/admin/api \\\n  underwater-game-admin\n```\n\n### Docker Compose Integration\n\nThe admin dashboard is integrated into the main `docker-compose.production.yml`:\n\n```yaml\nadmin:\n  build:\n    context: .\n    dockerfile: admin-dashboard/Dockerfile\n  container_name: underwater_game_admin\n  environment:\n    - VITE_API_URL=${ADMIN_API_URL}\n    - VITE_ENVIRONMENT=${REACT_APP_ENVIRONMENT}\n  depends_on:\n    - server\n  restart: unless-stopped\n```\n\n## API Integration\n\nThe dashboard connects to the game server's admin API endpoints:\n\n- **Authentication**: `/admin/api/auth/*`\n- **Users**: `/admin/api/users/*`\n- **Game Sessions**: `/admin/api/game/sessions/*`\n- **Content**: `/admin/api/content/*`\n- **System**: `/admin/api/system/*`\n- **Analytics**: `/admin/api/analytics/*`\n\n### Authentication Flow\n\n1. Admin logs in with credentials\n2. Server returns JWT token\n3. Token stored in localStorage\n4. All subsequent requests include Authorization header\n5. Token automatically refreshed before expiration\n\n## Environment Variables\n\n| Variable | Description | Default |\n|----------|-------------|---------|\n| `VITE_API_URL` | Backend API base URL | `http://localhost:8080/admin/api` |\n| `VITE_ENVIRONMENT` | Environment (development/production) | `development` |\n\n## Security Features\n\n### Authentication & Authorization\n- JWT-based authentication\n- Role-based access control\n- Session timeout management\n- Secure password requirements\n\n### Data Protection\n- HTTPS enforcement in production\n- XSS protection headers\n- CSRF protection\n- Input validation and sanitization\n\n### Network Security\n- Nginx reverse proxy configuration\n- Rate limiting for API endpoints\n- CORS configuration\n- Security headers (CSP, HSTS, etc.)\n\n## Performance Optimizations\n\n### Frontend Optimizations\n- Lazy loading of components\n- Code splitting with Vite\n- Tree shaking for smaller bundles\n- Image optimization and caching\n- Service worker for offline capabilities\n\n### Backend Integration\n- Request caching\n- Pagination for large datasets\n- Debounced search inputs\n- Optimistic updates\n- Background data refresh\n\n## Monitoring & Analytics\n\n### Built-in Monitoring\n- Real-time system metrics\n- Performance monitoring\n- Error tracking and logging\n- User activity analytics\n\n### Health Checks\n- Application health endpoint\n- Database connection status\n- External service monitoring\n- Automated alerts for issues\n\n## Customization\n\n### Theming\n- Tailwind CSS for styling\n- Custom color palette\n- Dark/light mode support\n- Responsive design\n\n### Extensibility\n- Modular component architecture\n- Plugin system for custom features\n- Hook-based state management\n- Type-safe API integration\n\n## Troubleshooting\n\n### Common Issues\n\n1. **Connection Refused**\n   -
